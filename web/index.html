    设置

    无论哪种策略，危险命令（rm -rf /、mkfs、关机等）都会强制确认。

    仅高亮匹配内容，保留程序原有颜色；支持常见日志与 Kubernetes 状态。vim / top 等全屏程序不应用规则。

    远端执行 sz 文件 下载到这里；rz 上传时会弹出本地文件选择框。

    添加一个 OpenAI 兼容供应商（Base URL + API Key），点「获取模型」会向上游 /models 拉取并自动加入全部模型，无需逐个勾选；之后按设定的间隔自动刷新同步。

    API Key 使用 Windows DPAPI 加密保存，界面与日志中不会出现明文。
